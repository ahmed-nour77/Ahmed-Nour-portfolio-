## 🌐 How to Deploy to GitHub Pages (Update your portfolio)

To update your live website at `https://ahmed-nour77.github.io/Ahmed-Nour-portfolio-/`:

1. Open Git Bash or terminal in this folder:
   ```bash
   git init
   git add .
   git commit -m "Update portfolio with modern AI theme, bilingual support, real projects, and photo"
   git branch -M main
   git remote add origin https://github.com/ahmed-nour77/Ahmed-Nour-portfolio-.git
   git push -u origin main --force
   ```
2. In GitHub repository settings:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment**, ensure Branch is `main` / `root`
   - Your site will be live in ~1-2 minutes!
